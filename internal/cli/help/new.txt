usage: shortcut new [-h] [--desc DESC] [--script PATH]
                    [--cwd CWD] [--local] [--namespace NAME]
                    [--confirm] name

Create a new shortcut

positional arguments:
  name                  Shortcut name

options:
  -h, --help            show this help message and exit
  --desc DESC           Shortcut description
  --script PATH         Run this file where it is
  --cwd CWD             Where it runs: caller (default) or a directory
  --local               Store it in .shortcuts.local in this directory, not
                        globally
  --namespace NAME      Put it in this namespace, creating
                        imports/NAME.shortcut if needed
  --confirm             Ask before running it
