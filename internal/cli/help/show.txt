usage: shortcut show [-h] [--global] [--json] [--field KEY] [namespace] name

Show shortcut details and content

positional arguments:
  name        Shortcut name, or namespace and name

options:
  -h, --help  show this help message and exit
  --json      Print the entry and where it resolves, as one JSON object
  --field KEY  Print one field, bare (name, scope, defined_in, script_path, description, icon, ...)
  --global    Skip this project's shortcuts, to reach a global one it hides
