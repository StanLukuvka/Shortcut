usage: shortcut rm [-h] [-y] [--global | --local] [namespace] name
       shortcut rm [-y] --namespace NS

Remove a shortcut, or a whole namespace

positional arguments:
  name            Shortcut name, or namespace and name

options:
  -h, --help      show this help message and exit
  --namespace NS  Remove this namespace from the global store, with its
                  scripts folder
  -y, --yes       Do not prompt for confirmation
  --local         Remove it from .shortcuts.local, or hide a shared shortcut
                  from you there
  --global        Skip this project's shortcuts, to reach a global one it
                  hides
