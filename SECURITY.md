# Security

## Reporting a vulnerability

Report it privately, through **Report a vulnerability** on the repository's Security tab. Don't open a public issue for it.

## Versions that get fixes

The latest release.

## What's in scope

The [Security model](README.md#security-model) in the README says what shortcut does and doesn't protect against. Something it lists as out of scope, such as someone who can already write to your shortcut store, isn't a vulnerability in shortcut.
